# Rose Compact 위젯 — 케이브덕 설정법

## 1. 위젯 콘텐츠
`rose-compact-widget.html` 내용 전체를 **위젯 콘텐츠 → 작성** 칸에 붙여넣기.
(에디터에서 각 `{{a}}`~`{{n}}` 자리가 아래 정보 이름과 연결됩니다.)

## 2. 정보 추가 (14개)
**+ 정보 추가**를 눌러 아래처럼 하나씩 만들기. 이름은 꼭 알파벳 소문자 한 글자로.

| 이름 | 지시사항 |
|---|---|
| a | 현재 장면과 분위기에 어울리는 실존 노래 제목을 작성하시오. |
| b | a 노래의 가수 이름을 작성하시오. |
| c | 이야기 속 현재 날짜를 YYYY.MM.DD 형식으로 작성하시오. |
| d | 현재 요일을 영문 대문자 3글자(MON, TUE, WED…)로 작성하시오. |
| e | 현재 시각이 오전이면 AM, 오후면 PM을 작성하시오. |
| f | 이야기 속 현재 시각을 12시간제 HH:MM 형식으로 작성하시오. |
| g | Pride와 Banshee가 현재 있는 장소를 한 문장으로 작성하시오. |
| h | Pride의 현재 자세를 한 문장으로 작성하시오. |
| i | Pride가 겉으로 말하지 않은 속마음을 1~2문장으로 작성하시오. |
| j | Pride가 Banshee에게 보내는 짧은 메시지를 1~2문장으로 작성하시오. |
| k | Pride의 현재 감정에 맞는 카오모지 1개를 작성하시오. |
| l | Banshee의 현재 감정에 맞는 카오모지 1개를 작성하시오. |
| m | Pride와 Banshee가 처음 만난 날을 YYYY.MM.DD 형식으로 작성하시오. |
| n | 처음 만난 날을 D+1로 하여 현재 날짜까지 계산한 디데이를 D+숫자 형식으로 작성하시오. |

## 3. 참고
- 위젯 **미리보기**에서는 값이 비어 보이는 게 정상이에요. 실제 채팅에서 AI가 채웁니다.
- 거울 뚜껑·속마음 칸은 탭하면 여닫힘 (`<details>` 사용).

## 직접 수정 가이드
코드에 `<!-- 장미 잠금쇠 -->`, `<!-- 핑크 팬 … -->`처럼 구역별 주석이 있어요.

| 바꾸고 싶은 것 | 찾을 값 |
|---|---|
| 핑크 팬 색 | `#f3e6ea`, `#e6d2d9`, `#efdfe4` |
| 라벤더 팬 색 | `#cfcfdc`, `#b5b4c6`, `#c9c8d6` |
| 차콜 팬 색 | `#56545f`, `#3f3d48`, `#4b4954` |
| 펄 팬 색 | `#f6f6f8`, `#dfe0e6` |
| 팬 테두리(검은 선) | `#2c2b33` |
| 장미 문양 | `❀` (다른 기호로 바꾸거나 지워도 됨) |
| 영문 글꼴 | `'Cormorant Garamond'` |
| 위젯 최대 너비 | 맨 첫 줄 `max-width:360px` |
| 바닥 각인 글씨 | `Rosée` |
| 처음에 닫힌 상태로 | `<details open` → `<details` |
