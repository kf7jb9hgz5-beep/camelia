# Rose Compact 위젯 — 케이브덕 사용법

은빛 섀도우 팔레트(장미 엠보싱 + 필리그리 문양) 컨셉의 상태창 위젯입니다.

## 파일
- `rose-compact-widget.html` — 케이브덕에 넣는 **템플릿** (`[ ]` 자리를 AI가 채움)
- `preview.html` / `preview.png` — 예시 데이터를 채운 미리보기
- `build.py` — 위젯 생성 스크립트 (디자인 수정 시 `python3 build.py .` 로 두 HTML 재생성)

## 구성
- 거울 뚜껑을 **탭하면 팔레트가 열리고 닫힘** (기본: 열림)
- 핑크 팬(속마음)도 탭해서 따로 여닫기 가능 (기본: 닫힘)

## 항목 기호표
| 기호 | 항목 | 위치 |
|---|---|---|
| a | 현재와 어울리는 노래 제목 | 거울 뚜껑 |
| b | 가수 | 거울 뚜껑 |
| c | 현재 날짜 (YYYY.MM.DD) | 거울 뚜껑 |
| d | 요일 (영문 3글자: MON, TUE…) | 거울 뚜껑 |
| e | AM / PM | 거울 뚜껑 |
| f | 현재 시각 (HH:MM, 12시간제) | 거울 뚜껑 |
| g | 현재 장소 | 브러시 홈 PLACE |
| h | 자세 | 브러시 홈 POSE |
| i | Pride의 속마음 | 핑크 팬 |
| j | Pride가 Banshee에게 보내는 메시지 | 라벤더 팬 |
| k | Pride 카오모지 | 차콜 팬 |
| l | Banshee 카오모지 | 펄 팬 |
| m | 처음 만난 날 (YYYY.MM.DD) | 하단 은판 |
| n | 만난 날 디데이 (D+N) | 하단 은판 |

## 프롬프트 (유저노트 / 캐릭터 지침에 붙여넣기)

```
[상태창 규칙]
매 응답의 맨 마지막에 아래 HTML 상태창을 반드시 출력한다.
HTML 구조와 style 속성은 절대 수정·생략하지 않고, {{a}}~{{n}} 자리만 아래 항목에 맞게 채운다. 중괄호와 기호는 지운다.
상태창은 코드블록(```)으로 감싸지 않는다.

a: 현재 분위기와 어울리는 실존 노래 제목
b: a의 가수
c: 이야기 속 현재 날짜 (YYYY.MM.DD)
d: 요일, 영문 3글자 대문자 (MON, TUE…)
e: AM 또는 PM
f: 현재 시각 (HH:MM, 12시간제)
g: 현재 장소, 한 문장
h: Pride의 현재 자세, 한 문장
i: Pride가 겉으로 말하지 않은 속마음, 1~2문장
j: Pride가 Banshee에게 보내는 짧은 메시지, 1~2문장
k: Pride의 현재 감정에 맞는 카오모지 1개
l: Banshee의 현재 감정에 맞는 카오모지 1개
m: Pride와 Banshee가 처음 만난 날 (YYYY.MM.DD)
n: 처음 만난 날을 D+1로 하여 현재 날짜까지 계산한 디데이 (D+N)

(여기에 rose-compact-widget.html 내용 전체를 붙여넣기)
```

## 직접 수정 가이드
`rose-compact-widget.html`은 `<!-- 장미 잠금쇠 -->`, `<!-- 핑크 팬 … -->`처럼 구역마다 주석이 달려 있어요. 각 구역 아래 줄의 `style="…"`만 고치면 됩니다.

| 바꾸고 싶은 것 | 찾을 값 |
|---|---|
| 핑크 팬 색 | `#f3e6ea`, `#e6d2d9`, `#efdfe4` |
| 라벤더 팬 색 | `#cfcfdc`, `#b5b4c6`, `#c9c8d6` |
| 차콜 팬 색 | `#56545f`, `#3f3d48`, `#4b4954` |
| 펄 팬 색 | `#f6f6f8`, `#dfe0e6` |
| 팬 테두리(검은 선) | `#2c2b33` |
| 영문 글꼴 | `'Cormorant Garamond'` |
| 위젯 최대 너비 | 맨 첫 줄 `max-width:360px` |
| 바닥 각인 글씨 | `Rosée` |
| 처음에 닫힌 상태로 | `<details open` → `<details` |

`url('data:image/svg+xml…')`로 시작하는 긴 값은 장미 문양 이미지라 건드리지 않는 게 좋아요.
