# Rose Compact 위젯 — 케이브덕 사용법

은빛 섀도우 팔레트(장미 엠보싱 + 필리그리 문양) 컨셉의 상태창 위젯입니다.

## 파일
- `rose-compact-widget.html` — 케이브덕에 넣는 **템플릿** (`[ ]` 자리를 AI가 채움)
- `preview.html` / `preview.png` — 예시 데이터를 채운 미리보기
- `build.py` — 위젯 생성 스크립트 (디자인 수정 시 `python3 build.py .` 로 두 HTML 재생성)

## 구성
| 위치 | 내용 |
|---|---|
| 거울 뚜껑 | ♪ 현재와 어울리는 노래 / 가수, 날짜·요일·시각 |
| 브러시 홈 2칸 | PLACE(현재 장소), POSE(자세) |
| 핑크 팬 | {{char}}의 속마음 (탭해서 펼치기) |
| 라벤더 팬 | {{char}} → {{user}} 메시지 |
| 차콜 / 펄 팬 | {{char}}, {{user}} 카오모지 |
| 하단 태그 | 처음 만난 날 + D-day |

## 프롬프트 (유저노트 / 캐릭터 지침에 붙여넣기)

```
[상태창 규칙]
매 응답의 맨 마지막에 아래 HTML 상태창을 반드시 출력한다.
- HTML 구조와 style 속성은 절대 수정·생략하지 않고, [ ]로 표시된 부분만 현재 상황에 맞게 채운다. 대괄호 자체는 지운다.
- 노래: 현재 분위기와 어울리는 실존 노래 1곡 (제목 / 가수)
- 날짜·시각: 이야기 속 현재 시점. 시간은 12시간제 + AM/PM, 요일은 영문 3글자(MON, TUE…)
- D-day: 처음 만난 날을 D+1로 하여 현재 날짜까지 계산
- 장소·자세: 한 문장으로 간결하게
- 속마음: {{char}}가 겉으로 말하지 않은 진짜 생각, 1~2문장
- 메시지: {{char}}가 {{user}}에게 보내는 짧은 메시지, 1~2문장
- 카오모지: 각자의 현재 감정에 맞는 카오모지 1개씩
- 상태창은 코드블록(```)으로 감싸지 않는다.

(여기에 rose-compact-widget.html 내용 전체를 붙여넣기)
```
