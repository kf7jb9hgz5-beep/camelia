# Artbook 위젯 — 케이브덕 설정법

흑백 일러스트북(설정집) 페이지 컨셉. 이미지·SVG 없이 글자 기호와 도형만 사용.

## 1. 위젯 콘텐츠
`artbook-widget.html` 전체를 **위젯 콘텐츠 → 작성** 칸에 붙여넣기.

## 2. 정보 추가 (16개)
| 이름 | 지시사항 |
|---|---|
| a | 현재 장면과 분위기에 어울리는 실존 노래 제목을 작성하시오. |
| b | a 노래의 가수 이름을 작성하시오. |
| c | 이야기 속 현재 날짜를 YYYY.MM.DD 형식으로 작성하시오. |
| d | 현재 요일을 영문 대문자 3글자(MON, TUE…)로 작성하시오. |
| e | 현재 시각이 오전이면 AM, 오후면 PM을 작성하시오. |
| f | 이야기 속 현재 시각을 12시간제 HH:MM 형식으로 작성하시오. |
| g | Pride와 Banshee가 현재 있는 장소를 한 문장으로 작성하시오. |
| h | Pride의 현재 자세를 한 문장으로 작성하시오. |
| i | Pride가 겉으로 말하지 않은 속마음을 1~2문장으로 작성하시오. |
| j | Pride가 Banshee에게 보내는 짧은 메시지를 1~2문장으로 작성하시오. |
| k | Pride의 현재 감정에 맞는 카오모지 1개를 작성하시오. |
| l | Banshee의 현재 감정에 맞는 카오모지 1개를 작성하시오. |
| m | Pride와 Banshee가 처음 만난 날을 YYYY.MM.DD 형식으로 작성하시오. |
| n | 처음 만난 날을 D+1로 하여 현재 날짜까지 계산한 디데이를 D+숫자 형식으로 작성하시오. |
| o | Pride의 현재 옷차림을 한 문장으로 작성하시오. |
| p | Banshee의 현재 옷차림을 한 문장으로 작성하시오. |

a~n은 Rose Compact 위젯과 같으니 그대로 두고 o, p만 추가하면 됩니다.
